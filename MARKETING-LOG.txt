2. TARGET PERSONAS & USER JOURNEYS
================================================================================
1. [PERSONA-01] Local AI Agent & Assistant Engineers (Claude Code, Antigravity, OpenAI Codex, Open-WebUI)
   - Needs: Run multi-step agentic workflows where agents generate tool calls, analyze code, and compact context, requiring safe local restore points between reasoning loops without leaking sensitive local file context to external cloud services.
   - Pain Points: Ad-hoc JSON dumps fail to verify data integrity, leading to silent prompt corruption; external cloud key-value stores violate privacy constraints and introduce network latency.
   - Solution: `session-checkpoint` provides an air-gapped local SQLite carrier with automatic canonical SHA-256 validation on every read. Machine-readable context in `llms.txt` enables local LLMs to invoke and inspect gating status natively.

2. [PERSONA-02] Desktop & GUI Application Developers (PySide6, PyQt, Tkinter, Electron)
   - Needs: Preserve session state (e.g. open documents, window geometry, active work tabs) across application restarts and unexpected operating system reboots.
   - Pain Points: Designing custom relational database schemas for session state introduces overhead; raw file saving risks corrupted files upon sudden power loss.
   - Solution: Lightweight Python API (`CheckpointStore`) provides ACID transaction guarantees via SQLite with zero background daemons.

3. [PERSONA-03] CLI Tool & Pipeline Automation Authors
   - Needs: Multi-stage ETL pipelines and batch processing scripts needing structured checkpoint history, repeatable dry-run deletion, and portable JSON migration bundles.
   - Pain Points: Shell scripts dumping files into temporary directories lack atomic rollback verification and namespace isolation.
   - Solution: Deterministic JSON-only CLI (`session-checkpoint`) with structured error codes, standard dry-run planning, and portable export/import commands.

4. [PERSONA-04] Security & Compliance-Conscious Teams
   - Needs: Developer tooling that guarantees zero data egress, unprivileged user execution, and strictly bounded memory and disk allocations.
   - Pain Points: Complex dependencies often introduce hidden network telemetry or security vulnerabilities.
   - Solution: 100% Local-First / Zero-Egress (INV-LOCAL-01), strictly unprivileged execution without UAC (INV-SEC-02), zero external runtime dependencies, 100% permissive open-source license audit (THIRD_PARTY_LICENSES.md), and codified 48-hour security response SLA (INV-SLA-10).
